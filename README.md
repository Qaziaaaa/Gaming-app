# Gaming App

Interactive 3D gaming showcase built with React, Three.js, and GSAP animations. Features immersive 3D scenes, smooth scroll animations, and a modern UI component library.

## Features

- 3D interactive scenes with Three.js and React Three Fiber
- GSAP-powered scroll animations
- Radix UI component primitives
- Framer Motion transitions
- Responsive design with Tailwind CSS

## Tech Stack

| Category | Technology |
|----------|-----------|
| Framework | React 19, TypeScript |
| 3D Engine | Three.js, React Three Fiber, Drei |
| Animation | GSAP, Framer Motion |
| UI Components | Radix UI, shadcn/ui patterns |
| Styling | Tailwind CSS |
| Forms | React Hook Form, Zod validation |
| Build Tool | Vite |

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Qaziaaaa/Gaming-app.git
cd Gaming-app

# Install dependencies
npm install

# Start development server
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start Vite dev server |
| `npm run build` | TypeScript build + Vite build |
| `npm run lint` | Run ESLint |
| `npm run preview` | Preview production build |
