# Gaming App

Interactive gaming-themed web application built with React and TypeScript. Features engaging UI components, game-inspired interactions, and responsive design.

## Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS

## Getting Started

1. Clone the repository
2. Install dependencies: \
pm install\
3. Run development server: \
pm run dev\
